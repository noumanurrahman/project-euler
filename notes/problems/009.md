Since $a + b + c = 1000$ and $a^2 + b^2 = c^2$, we have $a + b + \sqrt{a^2 + b^2} = 1000$.

This implies $a + b - 1000 = -\sqrt{a^2 + b^2}$.

Squaring both sides: $(a + b - 1000)^2 = a^2 + b^2$.

Expanding the left side: $a^2 + 2ab + b^2 - 2000(a + b) + 1000000 = a^2 + b^2$.

Simplifying: $2ab - 2000(a + b) + 1000000 = 0$.

Therefore: $ab - 1000(a + b) + 500000 = 0$.

We can solve it by iterating over possible values of a and b.

Since $a + b = 1000 - c$ where $c$ is a positive number, the possible values of $a$ and $b$ are from 1 to 999.

Also, since $a + b + c = 1000$, we can express $c$ as $c = 1000 - a - b$.
